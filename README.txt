THE EL BURROS — SHAREABLE WEBSITE

This folder is ready to publish on a free static host such as GitHub Pages or Netlify.

Files:
- index.html — website
- album-cover.jpg — album artwork
- Master_Of_Destruction.mp3 — song

GitHub Pages:
1. Create/sign into a GitHub account.
2. Create a new public repository.
3. Upload all 3 files to the repository.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select the main branch and / (root), then Save.
6. GitHub will provide the shareable github.io website address.

Netlify:
1. Create/sign into a Netlify account.
2. Use Netlify Drop and upload this folder (or its contents).
3. Netlify will provide a shareable netlify.app address.
